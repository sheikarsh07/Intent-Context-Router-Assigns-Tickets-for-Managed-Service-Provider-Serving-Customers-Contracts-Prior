2. QUANTITATIVE EVALUATION BENCHMARK FRAMEWORK (71% - 80% WORKLOAD)
--------------------------------------------------------------------------------
The evaluation engine (`src/evaluation.py`) performs automated quantitative benchmarking comparing the Baseline text-only router against the Context-Aware Router.

Evaluation Protocol:
- Dataset Split: 80% Training Set (440 tickets), 20% Held-Out Test Set (110 tickets), stratified by `correct_resolver`.
- Execution: Trains both models on the training split, predicts on the test set, and computes comparative metrics.

Mathematical Evaluation Formulas:
1. First-Assignment Accuracy: Accuracy = Correctly Assigned Tickets / Total Test Tickets
2. Bounce Rate: Bounce Rate = 1.0 - Accuracy = Bounced Tickets / Total Test Tickets
3. Weighted Precision: Sum(Weight_i * (TP_i / (TP_i + FP_i)))
4. Weighted Recall: Sum(Weight_i * (TP_i / (TP_i + FN_i)))
5. Weighted F1 Score: 2 * (Precision * Recall) / (Precision + Recall)
6. Accuracy Improvement %: ((Router_Accuracy - Baseline_Accuracy) / Baseline_Accuracy) * 100.0
7. Bounce Rate Reduction %: ((Baseline_Bounce - Router_Bounce) / Baseline_Bounce) * 100.0

Evaluation Output Artifacts:
- `results/metrics.json`: Stores numerical evaluation scores, per-class metrics, and confusion matrices.
- `results/error_analysis.csv`: Categorizes all misclassifications into error types (misleading text, missing context, conflicting context, ambiguous intent).
